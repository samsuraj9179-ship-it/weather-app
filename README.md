# 🌤️ Real-Time Weather Forecaster

A beautiful, interactive, and real-time weather application built with Python and Streamlit. This app features a premium "Glassmorphism" UI, dynamic background animations that change based on live weather conditions and local time, and interactive data visualizations.

## ✨ Features

* **Real-Time Weather Data:** Instantly fetches current temperature, "feels like" temperature, humidity, wind speed, pressure, visibility, and sunrise/sunset times for any global city.
* **Dynamic Background Animations:** The app background automatically changes to reflect the current weather and time of day (e.g., drifting clouds, falling rain/snow, twinkling night stars, and a pulsing sun).
* **Interactive 24-Hour Trends:** Beautiful, interactive Plotly area charts displaying 24-hour forecasts for Temperature, Precipitation, and Wind Speed.
* **5-Day Forecast:** A clean, easy-to-read 5-day forecast broken down into 3-hour intervals, complete with dynamic weather icons.
* **Premium UI/UX:** Built with custom CSS to create a modern, frosted-glass (Glassmorphism) aesthetic with glowing hover effects and a fully responsive layout.
* **Auto-Location Detection:** Uses IP geolocation to automatically load the weather for your current city upon launching.

## 🛠️ Technologies Used

* **Python 3.x**
* **Streamlit:** For the core web application framework.
* **Plotly:** For rendering the interactive 24-hour trend charts.
* **Requests:** For handling API calls.
* **OpenWeatherMap API:** For fetching real-time weather and forecast data.
* **Custom CSS/HTML:** For the Glassmorphism styling and keyframe background animations.
